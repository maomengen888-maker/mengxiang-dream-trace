# 梦象 Web PoC

“梦象”是一款可追溯传统解梦 Web 高保真原型。本阶段使用固定 fixtures 验证“记录—确认—纠错—澄清—检索—解释—卡片”工作流，不调用真实语音、模型、RAG 或文生图服务。

## 当前阶段

已实现第 1 阶段：

- 6 个受控页面状态：记录、转写、梦象确认、澄清、解析、结果；结果卡片与解释同时生成并留在同一页面。
- 正常演示路径“旧宅、蛇与古井”。
- “古镜→古井”低置信词纠错、梦象编辑/删除、单轮澄清。
- 返回纠正后 `inputRevision` 递增，旧解释与旧卡片失效。
- `sessionStorage` 会话恢复与“清除本次梦境”。
- P.3908 主版本来源登记、10 条待核验知识模板和严格的 `verified` 门禁。
- 默认高权重语音入口，同时始终保留文字输入。
- 解析过程插入与已确认梦象匹配的三格漫画，按“场景—动作—关系—解释”四层逐步显影，并保留跳过入口。
- 一次性水墨结果卡片、明确的长解释/一句话总结/关注建议，以及模拟保存和复制。
- 结果页顶部提供“返回梦象确认”，保留已输入内容并按新修订版重新生成；回到首页仍是独立操作。
- TypeScript、Zod、ESLint、Vitest、Testing Library 与 Playwright 验证。

尚未实现：模糊路径、无直接出处路径、完整失败/危机状态、真实 AI、生产知识库、后端、登录、数据库和部署级合规。这些能力不能从当前原型推断为已完成。

## 来源边界

主版本：敦煌写本 Pelliot chinois 3908（P.3908）《新集周公解梦书》，法国国家图书馆藏。

- 馆藏记录：<https://archivesetmanuscrits.bnf.fr/ark:/12148/cc1205597>
- 数字影像：<https://gallica.bnf.fr/ark:/12148/btv1b8300230n>

选定主版本不等于具体条目已经核验。当前 10 条知识记录均为 `pending`；只有逐页记录原文、叶面/栏位、核验人和日期后，才能标记 `verified` 并展示“直接记载”。

## 本地运行

要求：Node.js `>=22.13.0`、npm。

```bash
npm install
npm run dev
```

开发服务器会输出实际本地地址。3000 端口被占用时会自动使用下一个可用端口。

## 验证

```bash
npm run typecheck
npm run lint
npm run test:unit
npm run build
```

端到端测试需要先启动开发服务器，并确保 Playwright Chromium 已安装：

```bash
npx playwright install chromium
PLAYWRIGHT_BASE_URL=http://localhost:3001 npm run test:e2e
```

如果本地地址不是 3001，请替换 `PLAYWRIGHT_BASE_URL`。

## 正常路径验收

1. 首页点击“填入示例梦境”，再点击“记下这个梦”。
2. 在转写页把低置信词“古镜”改为“古井”并确认。
3. 在梦象页编辑一个元素、删除一个元素，再继续。
4. 回答“蛇有主动攻击你吗？”，查看蛇与古井三格漫画如何在四层解析中逐渐显影；也可直接跳过。
5. 在结果页区分“综合解释”和“待核验来源”，展开 P.3908 来源边界。
6. 查看结果页自动生成的一次性卡片，确认没有“重新生成”入口，并演示保存或复制摘要。
7. 点击“纠正梦象”，确认修订号增加且旧派生产物失效。
8. 刷新页面确认最近确认点可恢复；点击顶部“梦象”并确认后清除本次会话。

## 隐私与调试

- 本项目不需要 `.env` 或模型 Key。
- 解析页漫画是预生成的本地演示资产，并非每次输入后实时调用文生图。
- 本地演示事件只记录 PRD 白名单中的状态、枚举和计数，不记录完整梦境、来源原文、语音或密钥。
- 排查问题时请提供页面、操作步骤、路径、修订号、可见错误与控制台截图；不要提交真实梦境或任何密钥。
