# 梦象 Web PoC

“梦象”是一款可追溯传统解梦 Web 高保真原型。本阶段使用固定 fixtures 验证“记录—梦象确认—澄清—检索—解释—卡片”工作流，不调用真实语音、模型、RAG 或文生图服务。

## 当前阶段

已实现第 1 阶段，并完成第 2 阶段第一条前端纵向切片：

- 5 个可见页面状态：记录、梦象确认、澄清、解析、结果；内容/转写确认页已移除，结果卡片与解释同时生成。
- 正常演示路径“旧宅、蛇与古井”。
- 文字提交或模拟语音结束后直接进入梦象确认；支持梦象编辑/删除与单轮澄清。
- 返回纠正后 `inputRevision` 递增，旧解释与旧卡片失效。
- `sessionStorage` 会话恢复与“清除本次梦境”。
- P.3908 主版本来源登记、10 条待核验知识模板和严格的 `verified` 门禁。
- 首页以文字框为主入口，语音按钮收拢到输入框下方，并提供“掉入悬崖、被蛇追、牙齿掉落、水中迷路”四个快捷开头；每条路径使用对应的结构化梦象和解释，不会统一套用蛇与古井。
- 首页加入月影、雾化梦象词、朱砂显影线与入场动效，并为约 390 px 手机宽度重排布局。
- 解析过程插入与已确认梦象匹配的三格漫画，按“场景—动作—关系—解释”四层逐步显影，并保留跳过入口。
- 一次性水墨结果卡片、明确的长解释/一句话总结/关注建议，以及模拟保存和复制。
- 结果页顶部提供“返回梦象确认”，保留已输入内容并按新修订版重新生成；回到首页仍是独立操作。
- TypeScript、Zod、ESLint、Vitest、Testing Library 与 Playwright 验证。
- 模糊水面路径：只有当“自己与水面的位置关系”确实不明确时，才追问一次“岸边 / 水中 / 记不清”；三种回答保留不同的解释与确定性。
- 无直接出处路径：输入“手机屏幕碎裂”会显示“演示知识库暂无直接记载”，不把现代物件偷换为古镜，也不强行生成相近古籍证据。
- 解析页会根据本次确认的梦象更新可见阶段文案，不再对所有输入固定显示蛇与古井。
- 视觉方向调整为“晨雾见象”：首页采用雾白浅蓝渐变、居中宋体大标题、悬浮白色输入卡和黑色胶囊主按钮；确认、澄清、解析与结果正文保持东方编辑式浅色阅读体验，仅最终分享卡片进入幽暗水墨。
- 首页增加轻量导航“历史梦境 / 关于来源 / 演示版”；历史入口明确说明当前尚未接入账户系统，来源入口直达 P.3908 数字影像。
- 社交分享预览同步为“雾白产品界面 × 墨夜结果卡片”，与站内新视觉保持一致。

尚未实现：解析失败重试、图片失败降级、危机阻断、来源缺失/冲突、真实 AI、生产知识库、后端、登录、数据库和部署级合规。这些能力不能从当前原型推断为已完成。

- 当前没有应用内登录；会话仅保存在当前浏览器的 `sessionStorage`，清除站点数据、关闭受控会话或更换设备后不会同步。
- 当前图片、语音、解析和卡片均为明确标注的前端演示能力，不调用真实模型或上传真实录音。

线上验收：使用有访问权限的账号打开上述 HTTPS 地址，在桌面或手机浏览器完成“输入梦境 → 梦象确认 → 按需澄清 → 解析 → 结果卡片”，并刷新页面确认当前会话可恢复。

## 来源边界

主版本：敦煌写本 Pelliot chinois 3908（P.3908）《新集周公解梦书》，法国国家图书馆藏。

- 馆藏记录：<https://archivesetmanuscrits.bnf.fr/ark:/12148/cc1205597>
- 数字影像：<https://gallica.bnf.fr/ark:/12148/btv1b8300230n>

选定主版本不等于具体条目已经核验。当前 10 条知识记录均为 `pending`；只有逐页记录原文、叶面/栏位、核验人和日期后，才能标记 `verified` 并展示“直接记载”。

## 本地运行

要求：Node.js `>=22.13.0`、npm。

```bash
npm install
npm run dev
```

开发服务器会输出实际本地地址。3000 端口被占用时会自动使用下一个可用端口。

## 验证

```bash
npm run typecheck
npm run lint
npm run test:unit
npm run build
```

端到端测试需要先启动开发服务器，并确保 Playwright Chromium 已安装：

```bash
npx playwright install chromium
PLAYWRIGHT_BASE_URL=http://localhost:3001 npm run test:e2e
```

如果本地地址不是 3001，请替换 `PLAYWRIGHT_BASE_URL`。

## 路径验收

1. 首页直接写入“旧宅、蛇与古井”示例梦境，再点击“进入梦象解析”。
2. 提交后直接进入梦象页，确认没有中间的内容/转写确认页。
3. 在梦象页编辑一个元素、删除一个元素，再继续。
4. 回答“蛇有主动攻击你吗？”，查看蛇与古井三格漫画如何在四层解析中逐渐显影；也可直接跳过。
5. 在结果页区分“综合解释”和“待核验来源”，展开 P.3908 来源边界。
6. 查看结果页自动生成的一次性卡片，确认没有“重新生成”入口，并演示保存或复制摘要。
7. 点击“纠正梦象”，确认修订号增加且旧派生产物失效。
8. 刷新页面确认最近确认点可恢复；点击顶部“梦象”并确认后清除本次会话。

模糊路径：输入“我梦见眼前是一片看不清的水面，四周很安静。”，在梦象页继续后分别选择“岸边 / 水中 / 记不清”，确认结果确定性和一句话总结随回答变化。

无出处路径：输入“我梦见手机屏幕突然碎裂，所有消息都看不清了。”，继续到结果页，确认出现“暂无直接记载”，来源详情显示“暂无候选条目”，页面中没有“古镜”类比。

## 隐私与调试

- 本项目不需要 `.env` 或模型 Key。
- 解析页漫画是预生成的本地演示资产，并非每次输入后实时调用文生图。
- 本地演示事件只记录 PRD 白名单中的状态、枚举和计数，不记录完整梦境、来源原文、语音或密钥。
- 排查问题时请提供页面、操作步骤、路径、修订号、可见错误与控制台截图；不要提交真实梦境或任何密钥。
